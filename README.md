# media-instagram

Temporary image storage for the automatic publishing of Instagram carousels
for the **Final Step Bitcoin** channel.

This is **not a website**. Instagram's API cannot accept image files uploaded
directly from a computer: it only accepts a public URL that Meta's servers
fetch themselves. This repository exists solely to provide that URL.

The images here are the same slides published on
[@finalstepbitcoin](https://www.instagram.com/finalstepbitcoin/).

Files are removed once the carousel has been published.
